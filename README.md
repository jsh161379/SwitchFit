# ⌨️ SwitchFit

**C# WinForms를 사용한 키보드 스위치 추천 및 타건 체험 프로그램**

사용 환경과 취향(소음·키감·키압)에 맞는 키보드 스위치를 추천하고, 녹음된 타건음을 키 입력에 맞춰 재생해 스위치별 소리를 비교할 수 있는 프로그램입니다.

▶️ **[시연 영상 보기](https://youtu.be/rTTk_L4eoik)**

## 2. 프로그램 흐름

```text
설문 (소음 · 키감 · 키압)
   ↓
스위치 추천 (18종 중 조건 일치 1종)
   ↓
타건존 (목록 · 필터로 스위치 선택)
   ↓
키 입력 (KeyDown)
   ↓
타건음 재생 (5채널 교차 재생)

※ 타건존에서 쿠팡 최저가 · 네이버 검색으로 연결
```

## 3. 주요 기능

### 스위치 추천
- 소음(저소음·반저소음·일반), 키감(리니어·택타일), 키압(가벼움·표준·묵직함)을 설문으로 선택
- 세 조건을 모두 만족하는 스위치 1종을 추천하고, 결과 복사 기능 제공
- `타건하러 가기`를 누르면 추천 스위치가 선택된 상태로 타건존으로 이동

### 타건 체험
- 18종 스위치 목록에서 원하는 스위치를 선택하고, 소음·키감·키압 필터로 목록 정리
- 입력 영역에서 키를 누르면 선택한 스위치의 녹음 타건음 재생
- 선택한 스위치의 키압·소음 수준을 막대로 표시

### 외부 검색
- 선택한 스위치 이름으로 쿠팡 최저가 검색과 네이버 검색 연결

## 4. 문제 해결 — 연속 입력 시 소리 누락

| 구분 | 내용 |
|---|---|
| 문제 | 빠르게 연속 입력하면 이전 음원 재생 중에 다음 입력이 들어와 소리가 누락되거나 늦게 들림 |
| 원인 | 입력 간격이 음원 재생 시간보다 짧아 하나의 채널에 재생 요청이 겹침 |
| 해결 | 같은 음원을 5개 채널에 미리 등록하고, KeyDown마다 다음 채널을 순환하며 재생 |
| 결과 | 이전 소리가 재생 중이어도 다음 입력의 소리를 다른 채널에서 바로 재생 |

## 5. 프로젝트 구조

```text
SwitchFit/
├── Program.cs             # 프로그램 진입점
├── Form1.cs               # 메인 폼
├── UcSurveyPage.cs        # 설문(조건 선택) 화면
├── FormSurveyResult.cs    # 추천 결과 창
├── UcSwitchListPage.cs    # 타건존(목록·필터·타건·검색)
├── SwitchModel.cs         # 스위치 데이터 모델
├── SwitchRepository.cs    # 18종 스위치 데이터 및 추천 로직
├── SwitchAudioPlayer.cs   # MCI 기반 5채널 타건음 재생
└── UIHelper.cs            # 공통 UI 스타일
```
